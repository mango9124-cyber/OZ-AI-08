🛠️ merge  

    ✔️ fast forward  
        main + branch  
            merge 후 👉 branch -D feat/ai  
            (main 과 병합 후 feature 필요없으니 삭제)  
            (branch 목록 사라져도 커밋된 기록(데이터)은 남아있음)  
    ✔️ 3-way 병합 커밋  
        branch + branch  
        💥 conflict  
            서로 다른 branch에서 같은 파일의 같은 줄을 다르게 수정 후 합칠 때  
            충돌 부분을 직접 수정해야 함.  
            그 후 git add ➡️ git commit  
            merge commit 완료  
            🧶 비유하자면: 공동으로 쓰는 한 권의 공책(메인 파일)이 있습니다.   
            팀원 A는 책의 10페이지에 "여기에 선물하기 내용을 적어야지" 하고 적었고,   
            팀원 B도 자기 컴퓨터에서 똑같은 10페이지를 보며 "여기에 게임 내용을 적어야지"   

🛠️ Git 전체 구조 및 상태 파악  
    ✔️ 상태 및 전체 기록 확인 명령어  
        git ls-files   
            Repository에 commit된 최종 명단✨ 만 확인  
        ls -al  
            (요약 버전 + 숨긴 파일+ 상세정보까지)  
            ls (요약 버전)  
            ls -a (요약 버전+ 숨긴파일까지)  
            ls -l (요약 버전+ 상세 정보까지)  

        git status (working dir + staging)  
        git log (commit 완료된 기록까지)  
    ✔️ local vs global  
        git config --global user.name/user.email  
            commit 시 내 정보 남기기 위한 초기 설정  
        git log origin/main..main --oneline  
            commmit 완료, 아직 push 전 단계 체크  
        git push origin main  
            commit 완료 파일 업로드
